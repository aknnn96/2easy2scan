Home screen and offline

How to use 2simple2scan offline:

  1. Open this page online once and wait for “Offline ready” below.
  2. Install the app or add it to your home screen from the Chrome menu.
  3. Then open it from the home screen icon without internet to scan, edit and save PDFs.

Checking the offline copy …

Chrome has not offered direct installation yet. The button becomes active when the native dialog is available.

If the button stays disabled, use Chrome menu ⋮ → “Add to Home screen”. This shortcut can also open the prepared offline copy.

Scans are stored locally in this browser. If website data or browser storage is cleared, open the page online to prepare it again. Save important documents as PDFs.
